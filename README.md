HR Employee Attrition Analysis & Prediction
Project Overview
This project analyzes employee data to find out why people leave the company.I used python for data visualization and built a machine learning model to predict future attrition.
Model Performance:The Random Forest model achieved 84% accuracy in predicting employee turnover.
Tools used: Python,Pandas, Seaborn,Matplotlib
Machine Learning: scikit-learn(Random Forest)
Platform: Google colab
